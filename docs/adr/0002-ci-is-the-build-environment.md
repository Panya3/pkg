# CI คือ build environment ของ hub

hub นี้ไม่ถูก configure/build บนเครื่องนักพัฒนาเลย — GitHub Actions (`windows-2022`) เป็นคน configure, build และเก็บ artifact ส่วนเครื่องนักพัฒนาใช้แค่อ่านโค้ดกับ commit เพราะการมี CMake/MSVC สองชุดบนเครื่องที่ไม่มีอะไรบังคับให้ตรงกัน สร้างคำตอบคนละแบบกับ CI ได้ง่ายกว่าที่คิด

## Consequences

- CMake version ที่ใช้คือเวอร์ชันที่ CI image มี พร้อม step ตรวจว่าต่ำกว่า 3.25 ไม่ได้ (สมาชิกที่ต้องการสูงสุดคือ `yacppl` ที่ 3.25) — ยังไม่ pin เลขเวอร์ชันตายตัว เพราะยังไม่มีเหตุให้ต้องทำ และ pin ผ่าน third-party action เพิ่มความเสี่ยงมากกว่าที่ลด
- การยืนยันผลคือ "CI เขียว + `bin/` มี artifact ครบ" ไม่ใช่ "รันผ่านบนเครื่อง"
- การทดลองทั้งหมดเกิดบน branch ทดลอง ไม่ใช่ `main`
